# 🌤️ Weather Dashboard Application

A sleek, responsive cross-platform weather dashboard built with **React Native** and **Expo**. This application fetches live weather data and displays essential forecasts with a modern UI interface.

---

## 🚀 Features

* **Real-time Weather Data:** Displays current temperature, weather conditions, and atmospheric details.
* **Location Search:** Easily search weather details for any city or location globally.
* **Cross-Platform:** Runs seamlessly on Android, Web, and iOS.
* **Responsive UI:** Clean and intuitive UI styled for mobile devices.

---

## 🛠️ Tech Stack & Tools

* **Framework:** React Native (Expo SDK 51)
* **Language:** JavaScript / JSX
* **Build System:** Expo Application Services (EAS Build)
* **Package Manager:** npm

---

## 💻 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/roshanfds/weather-dashboard.git](https://github.com/roshanfds/weather-dashboard.git)
   cd weather-dashboard
Install dependencies:

Bash
npm install
Start the development server:

Bash
npx expo start
Run on target platform:

Press a for Android Emulator

Press w for Web Browser

Scan the QR code using Expo Go app on your physical mobile device.

📱 Build APK
To generate a standalone Android preview APK using EAS:

Bash
npx eas-cli@latest build -p android --profile preview
